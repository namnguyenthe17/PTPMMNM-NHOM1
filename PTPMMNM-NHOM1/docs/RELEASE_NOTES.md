# Lịch sử phát triển

## v4.0 – BTL Đề tài 1

- Phân phối tính năng theo phần trăm ổn định SHA-256, danh sách cho phép/chặn, điều kiện nhóm.
- Bản phát hành bất biến; chỉnh nháp, so sánh, phát hành, rollback sang bản mới, ghi lịch sử.
- API PHP có xác thực khóa và ứng dụng demo độc lập với fallback OFF.
- Phân quyền xem/sửa theo dự án, ghi log quyết định, nhập/xuất JSON kiểm tra dữ liệu.
- Bổ sung 13 tính năng, 3 nhóm, 1.000 mã giả, 32 kiểm thử nghiệp vụ BTL, tài liệu mã nguồn mở.
- Chế độ MySQL tùy chọn có transaction, chưa chuẩn hóa quan hệ; cần nâng cấp nếu nghiệm thu yêu cầu.
